# NOVA RESCUE — PromptWars Business Rescue Prototype

## Concept
A functional local-commerce control center focused on the case's connected failure pattern:

**stale inventory → unavailable product → cancellation/substitution → refund/support → lower repeat purchase**

The prototype deliberately combines three workflows:
1. **Inventory Guard** — prioritize at-risk SKUs and generate store interventions.
2. **Customer Rescue** — prioritize recovery actions without relying on blanket discounts.
3. **Impact Simulator** — translate target improvements into transparent scenario calculations.

## Run
Open `index.html` in any modern browser. No server, build step, package install, API key, or internet connection is required.

## Demo journey
1. Overview → Run Rescue Scan.
2. Inventory Guard → select an at-risk SKU → Act → Apply intervention.
3. Customer Rescue → Generate recovery actions.
4. Impact Simulator → change targets → Calculate scenario.

## Case evidence used
The UI uses the supplied challenge brief's documented figures, including repeat purchase decline (41% to 27%), cancellation increase (6% to 11%), delivery increase (29 to 37 minutes), support-ticket increase (3,100 to 5,900), and the 35% share of cancellations attributed to product unavailability.

## Important demo note
All store/customer rows are synthetic demonstration records. Financial impact is explicitly a scenario model, not a claim of actual NOVA CART results.
